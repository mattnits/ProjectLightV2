I am building a game engine from scratch with the end goal to build a simple playable game inside of it.

This project was built from scratch because I played around with building games in Unity and Unreal Engine and was very easily overwhelmed by the various options and pieces that needed to fit together to build simple game components. Naturally instead of just learning how to do it inside either engine, I wanted to learn from the fundimentals as to how the whole engine comes together from a low level. I had an initial attempt where I learned a lot about simple graphics fundamentals, linking librarys and dll's, and general C++ syntex. Since then I have gained a ton more knowledge and grown a lot as a developer and thought I would give it another go but starting again with my newfound knowledge.

Work is still in the very early stages!
